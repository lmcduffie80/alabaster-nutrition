# Milestone 1 — Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A branded iPhone/iPad/Mac app where the owner creates the Alabaster Nutrition business and adds employees by name, with the data syncing through the owner's iCloud so the store iPad and the owner's other devices show the same team. This is the base for Milestone 2 (the store iPad kiosk with PIN clock-in).

**Architecture:** All logic lives in a local Swift package, `AlabasterKit`, split into `Domain` (pure rules), `Brand` (colors, fonts, shapes), `Persistence` (Core Data + CloudKit), and `Features` (SwiftUI screens and the `AppModel`). A thin app shell generated by XcodeGen wires them together for iOS and macOS. The `Kiosk` module arrives in Milestone 2 and the `Sharing` module (phone-app invites) in Milestone 5. Spec: `docs/superpowers/specs/2026-11-08-scheduling-timekeeping-design.md`.

**Tech Stack:** Swift 6 toolchain, SwiftUI, Swift Testing, Core Data with `NSPersistentCloudKitContainer`, XcodeGen.

---

## Conventions

- **Swift language modes:** `Domain`, `Brand`, and `Features` use Swift 6 mode. `Persistence` and the app shell use Swift 5 mode, because Core Data and CloudKit types are not `Sendable` and strict mode adds noise without safety benefit in that glue code.
- **Running SwiftPM commands:** SwiftPM uses its own sandbox, which conflicts with agent sandboxes. Run every `swift build` / `swift test` command with the agent sandbox disabled.
- **Working directory:** all `swift` commands run from `AlabasterKit/`. All `git` commands run from the repository root.
- **Tasks 1–12 need only the Command Line Tools.** Tasks 13–15 need full Xcode, XcodeGen, and an Apple Developer account.
- **Deferred to Milestone 6 (polish):** the ginger-jar pattern illustration and the app icon. Both need artwork; this milestone uses the framed panel and wordmark only, and the app builds with the default icon.
- **Zone rule for later milestones:** when the Business is shared with employee phones (Milestone 5), `NSPersistentCloudKitContainer.share(_:to:)` moves the `Business` object *and every object reachable through its relationships* into the shared zone. Timekeeping entities added in Milestone 2 (`EmployeePIN`, `TimePunch`, `TimesheetAdjustment`, `TimesheetApproval`) must therefore have **no Core Data relationships** to `Business` or `Employee`; they reference employees by an `employeeID` UUID attribute so they stay in the owner's unshared private zone.

import Foundation

public enum BusinessDraftError: Error, Hashable, Sendable {
    case emptyName
    case emptyOwnerName
    case unknownTimeZone
    case missingClockOutOutOfRange
    case kioskAutoReturnOutOfRange

    public var message: String {
        switch self {
        case .emptyName: "Enter the business name."
        case .emptyOwnerName: "Enter your name."
        case .unknownTimeZone: "Choose a valid time zone."
        case .missingClockOutOutOfRange: "The missing clock-out reminder must be between 4 and 24 hours."
        case .kioskAutoReturnOutOfRange: "The store iPad must return to the keypad within 5 to 60 seconds."
        }
    }
}

public struct BusinessDraft: Equatable, Sendable {
    public static let missingClockOutRange: ClosedRange<Double> = 4...24
    public static let kioskAutoReturnRange: ClosedRange<Int> = 5...60

    public var name: String
    public var ownerName: String
    public var timeZoneIdentifier: String
    public var payPeriodRule: PayPeriodRule
    public var payPeriodAnchor: Date
    public var missingClockOutHours: Double
    public var kioskAutoReturnSeconds: Int

    public init(
        name: String,
        ownerName: String,
        timeZoneIdentifier: String,
        payPeriodRule: PayPeriodRule,
        payPeriodAnchor: Date,
        missingClockOutHours: Double,
        kioskAutoReturnSeconds: Int
    ) {
        self.name = name
        self.ownerName = ownerName
        self.timeZoneIdentifier = timeZoneIdentifier
        self.payPeriodRule = payPeriodRule
        self.payPeriodAnchor = payPeriodAnchor
        self.missingClockOutHours = missingClockOutHours
        self.kioskAutoReturnSeconds = kioskAutoReturnSeconds
    }

    public static func alabasterDefaults(ownerName: String, payPeriodAnchor: Date) -> BusinessDraft {
        BusinessDraft(
            name: "Alabaster Nutrition",
            ownerName: ownerName,
            timeZoneIdentifier: "America/New_York",
            payPeriodRule: .weekly,
            payPeriodAnchor: payPeriodAnchor,
            missingClockOutHours: 12,
            kioskAutoReturnSeconds: 10
        )
    }

    public func validationErrors() -> [BusinessDraftError] {
        var errors: [BusinessDraftError] = []
        if name.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty { errors.append(.emptyName) }
        if ownerName.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty { errors.append(.emptyOwnerName) }
        if TimeZone(identifier: timeZoneIdentifier) == nil { errors.append(.unknownTimeZone) }
        if !Self.missingClockOutRange.contains(missingClockOutHours) { errors.append(.missingClockOutOutOfRange) }
        if !Self.kioskAutoReturnRange.contains(kioskAutoReturnSeconds) { errors.append(.kioskAutoReturnOutOfRange) }
        return errors
    }
}
```

import Foundation

public enum EmployeeNameError: Error, Hashable, Sendable {
    case empty
    case duplicate

    public var message: String {
        switch self {
        case .empty: "Enter the employee's name."
        case .duplicate: "Someone on the team already has that name. Add a last initial to tell them apart."
        }
    }
}

public struct NewEmployee: Equatable, Sendable {
    public var displayName: String
    public var colorIndex: Int

    public init(displayName: String, colorIndex: Int) {
        self.displayName = displayName
        self.colorIndex = colorIndex
    }
}

public enum TeamRoster {
    /// Must match `BrandPalette.employeeColors.count`.
    public static let paletteSize = 8

    public static func newEmployee(named name: String, existing: [Employee]) throws -> NewEmployee {
        let trimmed = name.trimmingCharacters(in: .whitespacesAndNewlines)
        guard !trimmed.isEmpty else { throw EmployeeNameError.empty }
        let taken = existing.contains { $0.isActive && $0.displayName.caseInsensitiveCompare(trimmed) == .orderedSame }
        guard !taken else { throw EmployeeNameError.duplicate }
        return NewEmployee(displayName: trimmed, colorIndex: existing.count % paletteSize)
    }
}

public struct RGBA: Equatable, Sendable {
    public var red: Double
    public var green: Double
    public var blue: Double
    public var alpha: Double
}

public enum HexColor {
    /// Accepts `RRGGBB` or `RRGGBBAA`, with or without a leading `#`.
    public static func parse(_ string: String) -> RGBA? {
        var hex = Substring(string)
        if hex.hasPrefix("#") { hex = hex.dropFirst() }
        guard hex.count == 6 || hex.count == 8,
              hex.allSatisfy(\.isHexDigit),
              let value = UInt64(hex, radix: 16) else { return nil }
        func channel(_ shift: UInt64) -> Double { Double((value >> shift) & 0xFF) / 255 }
        if hex.count == 6 {
            return RGBA(red: channel(16), green: channel(8), blue: channel(0), alpha: 1)
        }
        return RGBA(red: channel(24), green: channel(16), blue: channel(8), alpha: channel(0))
    }
}
```

public struct BrandColor: Sendable {
    public let light: String
    public let dark: String

    public init(light: String, dark: String) {
        self.light = light
        self.dark = dark
    }

    public var color: Color {
        let fallback = RGBA(red: 0, green: 0, blue: 0, alpha: 1)
        let light = HexColor.parse(light) ?? fallback
        let dark = HexColor.parse(dark) ?? fallback
        #if canImport(UIKit)
        return Color(uiColor: UIColor { traits in
            let c = traits.userInterfaceStyle == .dark ? dark : light
            return UIColor(red: c.red, green: c.green, blue: c.blue, alpha: c.alpha)
        })
        #elseif canImport(AppKit)
        return Color(nsColor: NSColor(name: nil) { appearance in
            let isDark = appearance.bestMatch(from: [.darkAqua, .aqua]) == .darkAqua
            let c = isDark ? dark : light
            return NSColor(srgbRed: c.red, green: c.green, blue: c.blue, alpha: c.alpha)
        })
        #endif
    }
}

import SwiftUI

/// Rectangle with concave quarter-circle corners, matching the framed panel on the shop's sign.
public struct NotchedRectangle: InsettableShape {
    public var notch: CGFloat
    private var insetAmount: CGFloat = 0

    public init(notch: CGFloat = 14) {
        self.notch = notch
    }

    public func path(in rect: CGRect) -> Path {
        let r = rect.insetBy(dx: insetAmount, dy: insetAmount)
        let n = min(notch, r.width / 2, r.height / 2)
        var path = Path()
        path.move(to: CGPoint(x: r.minX + n, y: r.minY))
        path.addLine(to: CGPoint(x: r.maxX - n, y: r.minY))
        path.addArc(center: CGPoint(x: r.maxX, y: r.minY), radius: n,
                    startAngle: .degrees(180), endAngle: .degrees(90), clockwise: true)
        path.addLine(to: CGPoint(x: r.maxX, y: r.maxY - n))
        path.addArc(center: CGPoint(x: r.maxX, y: r.maxY), radius: n,
                    startAngle: .degrees(270), endAngle: .degrees(180), clockwise: true)
        path.addLine(to: CGPoint(x: r.minX + n, y: r.maxY))
        path.addArc(center: CGPoint(x: r.minX, y: r.maxY), radius: n,
                    startAngle: .degrees(360), endAngle: .degrees(270), clockwise: true)
        path.addLine(to: CGPoint(x: r.minX, y: r.minY + n))
        path.addArc(center: CGPoint(x: r.minX, y: r.minY), radius: n,
                    startAngle: .degrees(90), endAngle: .degrees(0), clockwise: true)
        path.closeSubpath()
        return path
    }

    public func inset(by amount: CGFloat) -> NotchedRectangle {
        var copy = self
        copy.insetAmount += amount
        return copy
    }
}

import CoreData

public enum AlabasterModel {
    /// One shared instance: multiple model instances with the same entities confuse Core Data.
    public static let shared: NSManagedObjectModel = makeModel()

    static func makeModel() -> NSManagedObjectModel {
        let business = NSEntityDescription()
        business.name = EntityName.business
        business.managedObjectClassName = NSStringFromClass(NSManagedObject.self)

        let employee = NSEntityDescription()
        employee.name = EntityName.employee
        employee.managedObjectClassName = NSStringFromClass(NSManagedObject.self)

        let employees = NSRelationshipDescription()
        employees.name = "employees"
        employees.destinationEntity = employee
        employees.minCount = 0
        employees.maxCount = 0
        employees.isOptional = true
        employees.deleteRule = .cascadeDeleteRule

        let owningBusiness = NSRelationshipDescription()
        owningBusiness.name = "business"
        owningBusiness.destinationEntity = business
        owningBusiness.minCount = 0
        owningBusiness.maxCount = 1
        owningBusiness.isOptional = true
        owningBusiness.deleteRule = .nullifyDeleteRule

        employees.inverseRelationship = owningBusiness
        owningBusiness.inverseRelationship = employees

        business.properties = [
            attribute("id", .UUIDAttributeType),
            attribute("name", .stringAttributeType),
            attribute("timeZoneIdentifier", .stringAttributeType),
            attribute("payPeriodRule", .stringAttributeType),
            attribute("payPeriodAnchor", .dateAttributeType),
            attribute("missingClockOutHours", .doubleAttributeType, default: NSNumber(value: 12.0)),
            attribute("kioskAutoReturnSeconds", .integer16AttributeType, default: NSNumber(value: 10)),
            attribute("createdAt", .dateAttributeType),
            employees,
        ]

        employee.properties = [
            attribute("id", .UUIDAttributeType),
            attribute("displayName", .stringAttributeType),
            attribute("role", .stringAttributeType, default: "employee"),
            attribute("colorIndex", .integer16AttributeType, default: NSNumber(value: 0)),
            attribute("isActive", .booleanAttributeType, default: NSNumber(value: true)),
            attribute("participantRecordName", .stringAttributeType),
            attribute("createdAt", .dateAttributeType),
            owningBusiness,
        ]

        let model = NSManagedObjectModel()
        model.entities = [business, employee]
        return model
    }

        let attribute = NSAttributeDescription()
        attribute.name = name
        attribute.attributeType = type
        attribute.isOptional = true

import CloudKit
import CoreData

public enum PersistenceError: Error {
    case storeMissing
}

public final class PersistenceController: @unchecked Sendable {
    public enum Mode: Sendable {
        case inMemory
        case cloudKit(containerIdentifier: String)
    }

    public let container: NSPersistentContainer
    /// Zones the current user owns.
    public let privateStore: NSPersistentStore
    /// Zones other people shared with the current user.
    public let sharedStore: NSPersistentStore

    public init(mode: Mode) throws {
        let container: NSPersistentContainer
        let privateDescription: NSPersistentStoreDescription
        let sharedDescription: NSPersistentStoreDescription

        switch mode {
        case .inMemory:
            container = NSPersistentContainer(name: "Alabaster", managedObjectModel: AlabasterModel.shared)
            privateDescription = Self.inMemoryDescription(named: "private")
            sharedDescription = Self.inMemoryDescription(named: "shared")
        case .cloudKit(let identifier):
            container = NSPersistentCloudKitContainer(name: "Alabaster", managedObjectModel: AlabasterModel.shared)
            privateDescription = Self.cloudKitDescription(named: "private", scope: .private, containerIdentifier: identifier)
            sharedDescription = Self.cloudKitDescription(named: "shared", scope: .shared, containerIdentifier: identifier)
        }

        container.persistentStoreDescriptions = [privateDescription, sharedDescription]
        var loadError: Error?
        container.loadPersistentStores { _, error in
            if let error { loadError = error }
        }
        if let loadError { throw loadError }

        let coordinator = container.persistentStoreCoordinator
        guard let privateURL = privateDescription.url,
              let sharedURL = sharedDescription.url,
              let privateStore = coordinator.persistentStore(for: privateURL),
              let sharedStore = coordinator.persistentStore(for: sharedURL) else {
            throw PersistenceError.storeMissing
        }

        container.viewContext.automaticallyMergesChangesFromParent = true
        container.viewContext.mergePolicy = NSMergeByPropertyObjectTrumpMergePolicy

        self.container = container
        self.privateStore = privateStore
        self.sharedStore = sharedStore
    }

    /// Debug-only: pushes the record types to the CloudKit development environment.
    public func initializeCloudKitSchema() throws {
        try (container as? NSPersistentCloudKitContainer)?.initializeCloudKitSchema(options: [])
    }

    private static func inMemoryDescription(named name: String) -> NSPersistentStoreDescription {
        let description = NSPersistentStoreDescription(url: URL(fileURLWithPath: "/dev/null").appendingPathComponent(name))
        description.type = NSInMemoryStoreType
        description.shouldAddStoreAsynchronously = false
        return description
    }

    private static func cloudKitDescription(
        named name: String,
        scope: CKDatabase.Scope,
        containerIdentifier: String
    ) -> NSPersistentStoreDescription {
        let url = NSPersistentContainer.defaultDirectoryURL().appendingPathComponent("\(name).sqlite")
        let description = NSPersistentStoreDescription(url: url)
        let options = NSPersistentCloudKitContainerOptions(containerIdentifier: containerIdentifier)
        options.databaseScope = scope
        description.cloudKitContainerOptions = options
        description.shouldAddStoreAsynchronously = false
        description.setOption(true as NSNumber, forKey: NSPersistentHistoryTrackingKey)
        description.setOption(true as NSNumber, forKey: NSPersistentStoreRemoteChangeNotificationPostOptionKey)
        return description
    }
}

    private let now: @Sendable () -> Date

    public init(controller: PersistenceController, now: @escaping @Sendable () -> Date = { Date() }) {
        self.controller = controller
        self.now = now
    }

    public func membership() async throws -> Membership {
        let context = controller.container.newBackgroundContext()
        let privateStore = controller.privateStore
        return try await context.perform {
            guard let object = try context.fetchBusinessObject() else { return .none }
            let business = Mapping.business(from: object)
            return object.objectID.persistentStore === privateStore ? .owner(business) : .member(business)
        }
    }

    public func createBusiness(from draft: BusinessDraft) async throws -> Business {
        let errors = draft.validationErrors()
        guard errors.isEmpty else { throw BusinessRepositoryError.invalidDraft(errors) }

        let context = controller.container.newBackgroundContext()
        let privateStore = controller.privateStore
        let createdAt = now()
        return try await context.perform {
            if try context.fetchBusinessObject() != nil {
                throw BusinessRepositoryError.businessAlreadyExists
            }

            let business = NSEntityDescription.insertNewObject(forEntityName: EntityName.business, into: context)
            context.assign(business, to: privateStore)
            business.setValue(UUID(), forKey: "id")
            business.setValue(draft.name.trimmingCharacters(in: .whitespacesAndNewlines), forKey: "name")
            business.setValue(draft.timeZoneIdentifier, forKey: "timeZoneIdentifier")
            business.setValue(draft.payPeriodRule.rawValue, forKey: "payPeriodRule")
            business.setValue(draft.payPeriodAnchor, forKey: "payPeriodAnchor")
            business.setValue(draft.missingClockOutHours, forKey: "missingClockOutHours")
            business.setValue(draft.kioskAutoReturnSeconds, forKey: "kioskAutoReturnSeconds")
            business.setValue(createdAt, forKey: "createdAt")

            let owner = NSEntityDescription.insertNewObject(forEntityName: EntityName.employee, into: context)
            context.assign(owner, to: privateStore)
            owner.setValue(UUID(), forKey: "id")
            owner.setValue(draft.ownerName.trimmingCharacters(in: .whitespacesAndNewlines), forKey: "displayName")
            owner.setValue(EmployeeRole.manager.rawValue, forKey: "role")
            owner.setValue(0, forKey: "colorIndex")
            owner.setValue(true, forKey: "isActive")
            owner.setValue(createdAt, forKey: "createdAt")
            owner.setValue(business, forKey: "business")

            try context.save()
            return Mapping.business(from: business)
        }
    }

    public func employees() async throws -> [Employee] {
        let context = controller.container.newBackgroundContext()
        return try await context.perform {
            try context.fetchEmployeeObjects().map(Mapping.employee(from:))
        }
    }

    public func addEmployees(_ newEmployees: [NewEmployee]) async throws {
        throw BusinessRepositoryError.noBusiness
    }
}

import Domain
import Observation
import Persistence

@MainActor
@Observable
public final class AppModel {
    public enum LoadState: Equatable, Sendable {
        case loading
        case loaded
        case iCloudUnavailable
        case failed(String)
    }

    public private(set) var loadState: LoadState = .loading
    public private(set) var membership: Membership = .none
    public private(set) var employees: [Employee] = []

    public var role: AppRole { membership.role }

    private let repository: any BusinessRepository
    private let accountStatus: any CloudAccountStatus

    public init(repository: any BusinessRepository, accountStatus: any CloudAccountStatus) {
        self.repository = repository
        self.accountStatus = accountStatus
    }

    public func refresh() async {
        guard await accountStatus.isAvailable() else {
            loadState = .iCloudUnavailable
            return
        }
        do {
            membership = try await repository.membership()
            employees = membership.business == nil ? [] : try await repository.employees()
            loadState = .loaded
        } catch {
            loadState = .failed(error.localizedDescription)
        }
    }

    public func createBusiness(_ draft: BusinessDraft) async throws {
        _ = try await repository.createBusiness(from: draft)
        await refresh()
    }

    /// Throws `EmployeeNameError` for a blank or duplicate name, and
    /// `BusinessRepositoryError.notOwner` when called on an employee's device.
    public func addEmployee(named name: String) async throws {
        guard case .owner = membership else { throw BusinessRepositoryError.notOwner }
        let newEmployee = try TeamRoster.newEmployee(named: name, existing: employees)
        try await repository.addEmployees([newEmployee])
        employees = try await repository.employees()
    }

    public func showError(_ message: String) {
        loadState = .failed(message)
    }
}

### Task 15: Spike — how employee phone requests get to the manager

Timekeeping no longer depends on this: punches are made on the store iPad and stay in the owner's private zone. What remains is the phone app (Milestone 5): each employee's availability, time-off, and swap requests live in a zone the employee owns, shared read-only with the manager, and that share must reach the manager without a second manual invite. Prove it on real devices before Milestone 5 is planned. Throwaway code lives on a `spike/employee-zone` branch and is not merged.

- [ ] **Step 1: Try Option A (spec design).** On the employee device, create an object in the private store, call `share([object], to: nil)`, look up the manager with `fetchParticipants(matching: [CKUserIdentity.LookupInfo(userRecordID:)], into:)` using the owner's `userRecordID` from the Business share, add them with `.readOnly` permission, and `persistUpdatedShare`. Then check whether the manager's device can accept it without the employee sending a link manually.

- [ ] **Step 2: Try Option B (fallback).** On the manager's device, create one zone per employee (`share([employeeZoneRoot], to: nil)`), add the employee as a `.readWrite` participant by `userRecordID`, and store the share URL on that employee's `Employee` record in the Business zone. On the employee device, read the URL, fetch metadata with `CKFetchShareMetadataOperation`, and accept it automatically. Only the added participant can accept, so the URL being visible to other employees does not grant access.
