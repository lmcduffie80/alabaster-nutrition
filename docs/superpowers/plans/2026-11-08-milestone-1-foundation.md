# Milestone 1 — Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A branded iPhone/iPad/Mac app where the owner creates the Alabaster Nutrition business (including the store iPad's time-clock settings), invites employees through iCloud sharing as groundwork for the Milestone 5 phone app, and each person automatically sees the manager or employee home screen.

> **Revision 2026-11-09:** The spec was revised for clock-in on a shared store iPad with 4-digit PINs. The location check (workplace coordinate and clock-in radius) is removed, and a kiosk auto-return delay is added; both changes are made in Task 13b. The invites and sharing built in Tasks 11–13 stay as groundwork for the Milestone 5 phone app. Task 16 moved to Milestone 5. The code blocks in Tasks 1–13 are historical; the committed source is authoritative.

**Architecture:** All logic lives in a local Swift package, `AlabasterKit`, split into `Domain` (pure rules), `Brand` (colors, fonts, shapes), `Persistence` (Core Data + CloudKit), `Sharing` (CloudKit invites), and `Features` (SwiftUI screens and the `AppModel`). A thin app shell generated by XcodeGen wires them together for iOS and macOS. Spec: `docs/superpowers/specs/2026-11-08-scheduling-timekeeping-design.md`.

**Tech Stack:** Swift 6 toolchain, SwiftUI, Swift Testing, Core Data with `NSPersistentCloudKitContainer`, CloudKit sharing, XcodeGen.

## Conventions

- **Swift language modes:** `Domain`, `Brand`, and `Features` use Swift 6 mode. `Persistence`, `Sharing`, and the app shell use Swift 5 mode, because Core Data and CloudKit types are not `Sendable` and strict mode adds noise without safety benefit in that glue code.
- **Running SwiftPM commands:** SwiftPM uses its own sandbox, which conflicts with agent sandboxes. Run every `swift build` / `swift test` command with the agent sandbox disabled.
- **Command Line Tools only:** SwiftPM does not find the Swift Testing macro plugin without Xcode. Until Xcode is installed, append `-Xswiftc -plugin-path -Xswiftc /Library/Developer/CommandLineTools/usr/lib/swift/host/plugins/testing` to every `swift build` and `swift test` command.
- **Working directory:** all `swift` commands run from `AlabasterKit/`. All `git` commands run from the repository root.
- **Tasks 1–13b need only the Command Line Tools.** Tasks 14–15 need full Xcode, XcodeGen, and an Apple Developer account.
- **Deferred to Milestone 6 (polish):** the ginger-jar pattern illustration and the app icon. Both need artwork; this milestone uses the framed panel and wordmark only, and the app builds with the default icon.

```swift
import Foundation

public enum BusinessDraftError: Error, Hashable, Sendable {
    case emptyName
    case emptyOwnerName
    case unknownTimeZone
    case invalidWorkplace
    case radiusOutOfRange
    case missingClockOutOutOfRange

    public var message: String {
        switch self {
        case .emptyName: "Enter the business name."
        case .emptyOwnerName: "Enter your name."
        case .unknownTimeZone: "Choose a valid time zone."
        case .invalidWorkplace: "The workplace location is invalid."
        case .radiusOutOfRange: "Clock-in distance must be between 50 and 1,000 meters."
        case .missingClockOutOutOfRange: "The missing clock-out reminder must be between 4 and 24 hours."
        }
    }
}

public struct BusinessDraft: Equatable, Sendable {
    public static let allowedRadiusRange: ClosedRange<Double> = 50...1_000
    public static let missingClockOutRange: ClosedRange<Double> = 4...24

    public var name: String
    public var ownerName: String
    public var timeZoneIdentifier: String
    public var payPeriodRule: PayPeriodRule
    public var payPeriodAnchor: Date
    public var workplace: Coordinate
    public var allowedRadiusMeters: Double
    public var missingClockOutHours: Double

    public init(
        name: String,
        ownerName: String,
        timeZoneIdentifier: String,
        payPeriodRule: PayPeriodRule,
        payPeriodAnchor: Date,
        workplace: Coordinate,
        allowedRadiusMeters: Double,
        missingClockOutHours: Double
    ) {
        self.name = name
        self.ownerName = ownerName
        self.timeZoneIdentifier = timeZoneIdentifier
        self.payPeriodRule = payPeriodRule
        self.payPeriodAnchor = payPeriodAnchor
        self.workplace = workplace
        self.allowedRadiusMeters = allowedRadiusMeters
        self.missingClockOutHours = missingClockOutHours
    }

    /// 101 E Front St, Sylvester, GA. The coordinate is approximate; the map picker in Milestone 3 refines it.
    public static func alabasterDefaults(ownerName: String, payPeriodAnchor: Date) -> BusinessDraft {
        BusinessDraft(
            name: "Alabaster Nutrition",
            ownerName: ownerName,
            timeZoneIdentifier: "America/New_York",
            payPeriodRule: .weekly,
            payPeriodAnchor: payPeriodAnchor,
            workplace: Coordinate(latitude: 31.5296, longitude: -83.8354),
            allowedRadiusMeters: 150,
            missingClockOutHours: 12
        )
    }

    public func validationErrors() -> [BusinessDraftError] {
        var errors: [BusinessDraftError] = []
        if name.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty { errors.append(.emptyName) }
        if ownerName.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty { errors.append(.emptyOwnerName) }
        if TimeZone(identifier: timeZoneIdentifier) == nil { errors.append(.unknownTimeZone) }
        if !workplace.isValid { errors.append(.invalidWorkplace) }
        if !Self.allowedRadiusRange.contains(allowedRadiusMeters) { errors.append(.radiusOutOfRange) }
        if !Self.missingClockOutRange.contains(missingClockOutHours) { errors.append(.missingClockOutOutOfRange) }
        return errors
    }
}
```

```swift
public enum AppRole: Equatable, Sendable {
    case needsSetup
    case manager
    case employee
}

/// The current user's relationship to the business. Ownership of the Business zone decides the role.
public enum Membership: Equatable, Sendable {
    case none
    case owner(Business)
    case member(Business)

    public var role: AppRole {
        switch self {
        case .none: .needsSetup
        case .owner: .manager
        case .member: .employee
        }
    }

    public var business: Business? {
        switch self {
        case .none: nil
        case .owner(let business), .member(let business): business
        }
    }
}
```

```swift
import Foundation

public struct ShareParticipantInfo: Equatable, Sendable {
    public var recordName: String
    public var displayName: String

    public init(recordName: String, displayName: String) {
        self.recordName = recordName
        self.displayName = displayName
    }
}

public struct NewEmployee: Equatable, Sendable {
    public var displayName: String
    public var participantRecordName: String
    public var colorIndex: Int

    public init(displayName: String, participantRecordName: String, colorIndex: Int) {
        self.displayName = displayName
        self.participantRecordName = participantRecordName
        self.colorIndex = colorIndex
    }
}

public enum ParticipantReconciler {
    /// Must match `BrandPalette.employeeColors.count`.
    public static let paletteSize = 8

    public static func newEmployees(
        acceptedParticipants: [ShareParticipantInfo],
        existing: [Employee]
    ) -> [NewEmployee] {
        var known = Set(existing.compactMap(\.participantRecordName))
        var nextColor = existing.count
        var result: [NewEmployee] = []
        for participant in acceptedParticipants where known.insert(participant.recordName).inserted {
            let trimmed = participant.displayName.trimmingCharacters(in: .whitespacesAndNewlines)
            result.append(NewEmployee(
                displayName: trimmed.isEmpty ? "New team member" : trimmed,
                participantRecordName: participant.recordName,
                colorIndex: nextColor % paletteSize
            ))
            nextColor += 1
        }
        return result
    }
}
```

```swift
public struct RGBA: Equatable, Sendable {
    public var red: Double
    public var green: Double
    public var blue: Double
    public var alpha: Double
}

public enum HexColor {
    /// Accepts `RRGGBB` or `RRGGBBAA`, with or without a leading `#`.
    public static func parse(_ string: String) -> RGBA? {
        var hex = Substring(string)
        if hex.hasPrefix("#") { hex = hex.dropFirst() }
        guard hex.count == 6 || hex.count == 8,
              hex.allSatisfy(\.isHexDigit),
              let value = UInt64(hex, radix: 16) else { return nil }
        func channel(_ shift: UInt64) -> Double { Double((value >> shift) & 0xFF) / 255 }
        if hex.count == 6 {
            return RGBA(red: channel(16), green: channel(8), blue: channel(0), alpha: 1)
        }
        return RGBA(red: channel(24), green: channel(16), blue: channel(8), alpha: channel(0))
    }
```

```swift
import SwiftUI

/// Rectangle with concave quarter-circle corners, matching the framed panel on the shop's sign.
public struct NotchedRectangle: InsettableShape {
    public var notch: CGFloat
    private var insetAmount: CGFloat = 0

    public init(notch: CGFloat = 14) {
        self.notch = notch
    }

    public func path(in rect: CGRect) -> Path {
        let r = rect.insetBy(dx: insetAmount, dy: insetAmount)
        let n = min(notch, r.width / 2, r.height / 2)
        var path = Path()
        path.move(to: CGPoint(x: r.minX + n, y: r.minY))
        path.addLine(to: CGPoint(x: r.maxX - n, y: r.minY))
        path.addArc(center: CGPoint(x: r.maxX, y: r.minY), radius: n,
                    startAngle: .degrees(180), endAngle: .degrees(90), clockwise: true)
        path.addLine(to: CGPoint(x: r.maxX, y: r.maxY - n))
        path.addArc(center: CGPoint(x: r.maxX, y: r.maxY), radius: n,
                    startAngle: .degrees(270), endAngle: .degrees(180), clockwise: true)
        path.addLine(to: CGPoint(x: r.minX + n, y: r.maxY))
        path.addArc(center: CGPoint(x: r.minX, y: r.maxY), radius: n,
                    startAngle: .degrees(360), endAngle: .degrees(270), clockwise: true)
        path.addLine(to: CGPoint(x: r.minX, y: r.minY + n))
        path.addArc(center: CGPoint(x: r.minX, y: r.minY), radius: n,
                    startAngle: .degrees(90), endAngle: .degrees(0), clockwise: true)
        path.closeSubpath()
        return path
    }

    public func inset(by amount: CGFloat) -> NotchedRectangle {
        var copy = self
        copy.insetAmount += amount
        return copy
    }
}
```

```swift
import CoreData

public enum AlabasterModel {
    /// One shared instance: multiple model instances with the same entities confuse Core Data.
    public static let shared: NSManagedObjectModel = makeModel()

    static func makeModel() -> NSManagedObjectModel {
        let business = NSEntityDescription()
        business.name = EntityName.business
        business.managedObjectClassName = NSStringFromClass(NSManagedObject.self)

        let employee = NSEntityDescription()
        employee.name = EntityName.employee
        employee.managedObjectClassName = NSStringFromClass(NSManagedObject.self)

        let employees = NSRelationshipDescription()
        employees.name = "employees"
        employees.destinationEntity = employee
        employees.minCount = 0
        employees.maxCount = 0
        employees.isOptional = true
        employees.deleteRule = .cascadeDeleteRule

        let owningBusiness = NSRelationshipDescription()
        owningBusiness.name = "business"
        owningBusiness.destinationEntity = business
        owningBusiness.minCount = 0
        owningBusiness.maxCount = 1
        owningBusiness.isOptional = true
        owningBusiness.deleteRule = .nullifyDeleteRule

        employees.inverseRelationship = owningBusiness
        owningBusiness.inverseRelationship = employees

        business.properties = [
            attribute("id", .UUIDAttributeType),
            attribute("name", .stringAttributeType),
            attribute("timeZoneIdentifier", .stringAttributeType),
            attribute("payPeriodRule", .stringAttributeType),
            attribute("payPeriodAnchor", .dateAttributeType),
            attribute("workplaceLatitude", .doubleAttributeType, default: NSNumber(value: 0.0)),
            attribute("workplaceLongitude", .doubleAttributeType, default: NSNumber(value: 0.0)),
            attribute("allowedRadiusMeters", .doubleAttributeType, default: NSNumber(value: 150.0)),
            attribute("missingClockOutHours", .doubleAttributeType, default: NSNumber(value: 12.0)),
            attribute("createdAt", .dateAttributeType),
            employees,
        ]

        employee.properties = [
            attribute("id", .UUIDAttributeType),
            attribute("displayName", .stringAttributeType),
            attribute("role", .stringAttributeType, default: "employee"),
            attribute("colorIndex", .integer16AttributeType, default: NSNumber(value: 0)),
            attribute("isActive", .booleanAttributeType, default: NSNumber(value: true)),
            attribute("participantRecordName", .stringAttributeType),
            attribute("createdAt", .dateAttributeType),
            owningBusiness,
        ]

        let model = NSManagedObjectModel()
        model.entities = [business, employee]
        return model
    }

    private static func attribute(_ name: String, _ type: NSAttributeType, default value: Any? = nil) -> NSAttributeDescription {
        let attribute = NSAttributeDescription()
        attribute.name = name
        attribute.attributeType = type
```

```swift
import CloudKit
import CoreData

public enum PersistenceError: Error {
    case storeMissing
}

public final class PersistenceController: @unchecked Sendable {
    public enum Mode: Sendable {
        case inMemory
        case cloudKit(containerIdentifier: String)
    }

    public let container: NSPersistentContainer
    /// Zones the current user owns.
    public let privateStore: NSPersistentStore
    /// Zones other people shared with the current user.
    public let sharedStore: NSPersistentStore

    public init(mode: Mode) throws {
        let container: NSPersistentContainer
        let privateDescription: NSPersistentStoreDescription
        let sharedDescription: NSPersistentStoreDescription

        switch mode {
        case .inMemory:
            container = NSPersistentContainer(name: "Alabaster", managedObjectModel: AlabasterModel.shared)
            privateDescription = Self.inMemoryDescription(named: "private")
            sharedDescription = Self.inMemoryDescription(named: "shared")
        case .cloudKit(let identifier):
            container = NSPersistentCloudKitContainer(name: "Alabaster", managedObjectModel: AlabasterModel.shared)
            privateDescription = Self.cloudKitDescription(named: "private", scope: .private, containerIdentifier: identifier)
            sharedDescription = Self.cloudKitDescription(named: "shared", scope: .shared, containerIdentifier: identifier)
        }

        container.persistentStoreDescriptions = [privateDescription, sharedDescription]
        var loadError: Error?
        container.loadPersistentStores { _, error in
            if let error { loadError = error }
        }
        if let loadError { throw loadError }

        let coordinator = container.persistentStoreCoordinator
        guard let privateURL = privateDescription.url,
              let sharedURL = sharedDescription.url,
              let privateStore = coordinator.persistentStore(for: privateURL),
              let sharedStore = coordinator.persistentStore(for: sharedURL) else {
            throw PersistenceError.storeMissing
        }

        container.viewContext.automaticallyMergesChangesFromParent = true
        container.viewContext.mergePolicy = NSMergeByPropertyObjectTrumpMergePolicy

        self.container = container
        self.privateStore = privateStore
        self.sharedStore = sharedStore
    }

    /// Debug-only: pushes the record types to the CloudKit development environment.
    public func initializeCloudKitSchema() throws {
        try (container as? NSPersistentCloudKitContainer)?.initializeCloudKitSchema(options: [])
    }

    private static func inMemoryDescription(named name: String) -> NSPersistentStoreDescription {
        let description = NSPersistentStoreDescription(url: URL(fileURLWithPath: "/dev/null").appendingPathComponent(name))
        description.type = NSInMemoryStoreType
        description.shouldAddStoreAsynchronously = false
        return description
    }

    private static func cloudKitDescription(
        named name: String,
        scope: CKDatabase.Scope,
        containerIdentifier: String
    ) -> NSPersistentStoreDescription {
        let url = NSPersistentContainer.defaultDirectoryURL().appendingPathComponent("\(name).sqlite")
        let description = NSPersistentStoreDescription(url: url)
        let options = NSPersistentCloudKitContainerOptions(containerIdentifier: containerIdentifier)
        options.databaseScope = scope
        description.cloudKitContainerOptions = options
        description.shouldAddStoreAsynchronously = false
        description.setOption(true as NSNumber, forKey: NSPersistentHistoryTrackingKey)
        description.setOption(true as NSNumber, forKey: NSPersistentStoreRemoteChangeNotificationPostOptionKey)
        return description
    }
}
```

```swift
import CloudKit
import CoreData
import Domain
import Persistence

public enum SharingError: Error {
    case noBusiness
    case notCloudKitContainer
}

public final class CloudKitBusinessSharing: BusinessSharing, @unchecked Sendable {
    private let controller: PersistenceController
    private let containerIdentifier: String

    public init(controller: PersistenceController, containerIdentifier: String) {
        self.controller = controller
        self.containerIdentifier = containerIdentifier
    }

    private var cloudContainer: NSPersistentCloudKitContainer? {
        controller.container as? NSPersistentCloudKitContainer
    }

    public func isICloudAvailable() async -> Bool {
        (try? await CKContainer(identifier: containerIdentifier).accountStatus()) == .available
    }

    public func shareItem() -> BusinessShareItem {
        BusinessShareItem(containerIdentifier: containerIdentifier) { [self] in
            try await existingOrNewShare()
        }
    }

    public func acceptedParticipants() async throws -> [ShareParticipantInfo] {
        guard let share = try await currentShare() else { return [] }
        let formatter = PersonNameComponentsFormatter()
        return share.participants.compactMap { participant in
            guard participant.role != .owner,
                  participant.acceptanceStatus == .accepted,
                  let recordName = participant.userIdentity.userRecordID?.recordName else { return nil }
            let name = participant.userIdentity.nameComponents.map { formatter.string(from: $0) } ?? ""
            return ShareParticipantInfo(recordName: recordName, displayName: name)
        }
    }

    /// Called from the app delegates when the user opens an invite link.
    public func acceptInvitation(_ metadata: CKShare.Metadata) async throws {
        guard let cloudContainer else { throw SharingError.notCloudKitContainer }
        _ = try await cloudContainer.acceptShareInvitations(from: [metadata], into: controller.sharedStore)
    }

    @MainActor
    private func currentShare() throws -> CKShare? {
        guard let cloudContainer else { throw SharingError.notCloudKitContainer }
        guard let business = try cloudContainer.viewContext.fetchBusinessObject() else { return nil }
        return try cloudContainer.fetchShares(matching: [business.objectID])[business.objectID]
    }

    @MainActor
    private func existingOrNewShare() async throws -> CKShare {
        guard let cloudContainer else { throw SharingError.notCloudKitContainer }
        guard let business = try cloudContainer.viewContext.fetchBusinessObject() else {
            throw SharingError.noBusiness
        }
        if let existing = try currentShare() { return existing }

        let (_, share, _) = try await cloudContainer.share([business], to: nil)
        let name = business.value(forKey: "name") as? String ?? "Alabaster Nutrition"
        share[CKShare.SystemFieldKey.title] = name as CKRecordValue
        share.publicPermission = .none
        _ = try await cloudContainer.persistUpdatedShare(share, in: controller.privateStore)
        return share
    }
}
```

```swift
/// Holds every `acceptedParticipants()` call until `open()`, and records how many ran at once.
actor GatedSharing: BusinessSharing {
    private let participants: [ShareParticipantInfo]
    private var isOpen = false
    private var waiters: [CheckedContinuation<Void, Never>] = []
    private var inFlight = 0
    private(set) var maxInFlight = 0
    private(set) var participantRequests = 0

    init(participants: [ShareParticipantInfo]) {
        self.participants = participants
    }

    var waitingCount: Int { waiters.count }

    func open() {
        isOpen = true
        waiters.forEach { $0.resume() }
        waiters.removeAll()
    }

    func isICloudAvailable() async -> Bool { true }

    func acceptedParticipants() async throws -> [ShareParticipantInfo] {
        participantRequests += 1
        inFlight += 1
        maxInFlight = max(maxInFlight, inFlight)
        defer { inFlight -= 1 }
        if !isOpen {
            await withCheckedContinuation { waiters.append($0) }
        }
        return participants
    }

    nonisolated func shareItem() -> BusinessShareItem {
        BusinessShareItem(containerIdentifier: "iCloud.test") { throw CKError(.notAuthenticated) }
    }
```

```swift
    @ObservationIgnored private var runningRefresh: Task<Void, Never>?
    @ObservationIgnored var refreshRequested = false
    @ObservationIgnored private var isJoining = false
    /// Set by `showError(_:)` and kept until `retry()`, so a background refresh cannot hide it.
    @ObservationIgnored private var pendingError: String?

    public init(repository: any BusinessRepository, sharing: any BusinessSharing) {
        self.repository = repository
        self.sharing = sharing
    }

    /// Runs one refresh at a time, so two owner refreshes cannot both add the same participant.
    /// Calls that arrive mid-refresh coalesce into a single follow-up run and return once it finishes.
    public func refresh() async {
        if let runningRefresh {
            refreshRequested = true
            await runningRefresh.value
            return
        }
        let task = Task {
            repeat {
                refreshRequested = false
                await performRefresh()
            } while refreshRequested
            runningRefresh = nil
        }
        runningRefresh = task
        await task.value
    }

    /// Clears a pending error and refreshes. Backs the "Try Again" buttons.
    public func retry() async {
        pendingError = nil
        await refresh()
    }

    /// A pending error outranks every state except `.iCloudUnavailable`, which the user must fix first;
    /// the error shows again once iCloud is back, until `retry()`.
    private func performRefresh() async {
        guard await sharing.isICloudAvailable() else {
            loadState = .iCloudUnavailable
            return
        }
        let state: LoadState
        do {
            membership = try await repository.membership()
            if case .owner = membership {
                try? await reconcileParticipants()
            }
            employees = membership.business == nil ? [] : try await repository.employees()
            if membership != .none {
                isJoining = false
            }
            state = isJoining ? .joining : .loaded
        } catch {
            state = .failed(error.localizedDescription)
        }
        loadState = pendingError.map(LoadState.failed) ?? state
    }

    public func createBusiness(_ draft: BusinessDraft) async throws {
        _ = try await repository.createBusiness(from: draft)
        await refresh()
    }

    /// Accepts an invite, then stays in `.joining` until the shared business syncs down,
    /// so the new employee is not sent to business setup in the meantime.
    public func acceptInvitation(_ accept: @escaping @Sendable () async throws -> Void) async {
        pendingError = nil
        isJoining = true
        loadState = .joining
        do {
            try await accept()
        } catch {
            isJoining = false
            showError("The invite couldn't be accepted: \(error.localizedDescription)")
            return
        }
        await refresh()
    }

    public func shareItem() -> BusinessShareItem? {
        guard case .owner = membership else { return nil }
        return sharing.shareItem()
    }

    public func showError(_ message: String) {
        pendingError = message
        loadState = .failed(message)
    }

    /// Best effort: a failure here leaves new participants for the next refresh to add.
    private func reconcileParticipants() async throws {
        let participants = try await sharing.acceptedParticipants()
        let newEmployees = ParticipantReconciler.newEmployees(
            acceptedParticipants: participants,
            existing: try await repository.employees()
        )
        if !newEmployees.isEmpty {
            try await repository.addEmployees(newEmployees)
        }
    }
}
```

```swift
    private func luminance(_ hex: String) throws -> Double {

        func linear(_ c: Double) -> Double { c <= 0.04045 ? c / 12.92 : pow((c + 0.055) / 1.055, 2.4) }
```
